# 🌊 Blox Fruits Browser Clone

لعبة ثلاثية الأبعاد (3D) مستوحاة من لعبة بلوكس فروت الشهيرة، مصممة لتعمل مباشرة على المتصفح باستخدام JavaScript و Three.js.

## ✨ الميزات الحالية:
- عالم 3D بالكامل يحتوي على جزيرة مخصصة للاعب.
- نظام قتال وزيادة الـ XP والمستويات (Level Up) وكسب المال (Beli).
- نظام فواكه شيطان تفاعلي (عند لمس الفاكهة يكتسب اللاعب سرعة إضافية وقوة نارية ويتغير لونه).

## 🎮 طريقة التحكم:
- **الحركة**: أزرار `W, A, S, D` أو الأسهم.
- **الضرب/الهجوم**: زر المسافة `Space` لتجميع الخبرة والـ Level up.
